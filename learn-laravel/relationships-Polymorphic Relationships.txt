Laravel supports three types of polymorphic relationships:

On child models belongs to diferent types of parent model like commnets may be for Post or User
Images may be for User or Product

One-to-One Polymorphic
(Example: An Image can belong to either a User or a Product.)

One-to-Many Polymorphic
(Example: A Comment can belong to either a Post or a Video.)

Many-to-Many Polymorphic
(Example: A Tag can belong to multiple Post and Video models.)

One-to-One Polymorphic Relationship
Example: A user and a product can each have one image.
http://127.0.0.1:8000/user-images-index
// Image.php
class Image extends Model
{
    public function imageable()
    {
        return $this->morphTo();
    }
}

// User.php
class User extends Model
{
    public function image()
    {
        return $this->morphOne(Image::class, 'imageable');
    }
}

// Product.php
class Product extends Model
{
    public function image()
    {
        return $this->morphOne(Image::class, 'imageable');
    }
}

Many-to-Many Polymorphic Relationship
Example: Both Post and Video can be tagged with many Tags.
	
	
	
morphs('name') → Creates name_id and name_type columns.
morphTo() → Used in child model to point back to the parent.
morphOne, morphMany, morphToMany, morphedByMany → Used in parent models.
Polymorphic relationships avoid creating separate foreign keys for each possible model.
