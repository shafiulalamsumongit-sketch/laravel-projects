Gate → General ability (no specific model)
Gate : Create it in AuthService provider


Policy → Permission on a specific model

1️⃣  Policy - direct model and model object
1️⃣  Source : https://chatgpt.com/c/69a532e1-0408-8322-9c58-3abc8093676f
1️⃣  Controller use : $this->authorize('update', $user);
1️⃣  Blade use : 
   @can('update', $product)
      <a href="{{ route('products.edit',$product) }}">Edit</a>
   @endcan

️⃣ Model CRUD Authorization
   Example: UserPolicy
   public function update(Admin $admin, Admin $model)
   {
		// Super admin can edit anyone
		if ($admin->role == 'super_admin') {
			return true;
		}
		// Admin cannot edit super admin
		return $model->role !== 'super_admin';
	}

1️⃣  Used in controller:
   $this->authorize('update', $user); // can update user 
   
📌 Use policy for:
- edit user
- delete user
- view user
- update product
- delete order
- update category


2️⃣  Protect Super Admin Records
Example: Prevent editing super admin
	public function delete(Admin $admin, Admin $model)
	{
		if ($model->role === 'super_admin') {
			return false;
		}
		return $admin->role === 'super_admin';
	}
Used when:
	deleting admin
	editing admin
	changing role


3️⃣ Ownership Based Access
	Example: Vendor can edit only their own products
	public function update(Vendor $vendor, Product $product)
	{
		return $vendor->id === $product->vendor_id;
	}
Used for:
vendor product edit
vendor order view
vendor stock management

4️⃣ Resource Viewing
Example:
public function view(Admin $admin, Product $product)
{
    return $admin->role === 'admin' || $admin->role === 'super_admin';
}
Used in:
$this->authorize('view', $product);

6️⃣ Multi Guard Authorization
Example for VendorPolicy
public function update(Vendor $vendor, Product $product)
{
    return $vendor->id === $product->vendor_id;
}
Used in:
Vendor dashboard
Vendor product CRUD
Vendor order management


7️⃣ API Authorization
Policies are very important in Laravel APIs.
Example:
public function show(Order $order)
{
    $this->authorize('view', $order);
    return $order;
}


8️⃣ Policy in Blade Templates
Example:
@can('update', $product)
    <a href="{{ route('products.edit',$product) }}">Edit</a>
@endcan
Used in:
show edit button
show delete button
show admin controls

9️⃣ Bulk Operations
Example:
foreach($products as $product){
    $this->authorize('delete', $product);
}
Used in:
bulk delete
bulk update
bulk archive

🔟 Route Level Authorization
Example:
Route::delete('/users/{user}', function(User $user){
    $this->authorize('delete', $user);
});
